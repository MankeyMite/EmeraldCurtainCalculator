# Starter guide screenshots

These six unmodified 240 × 160 English Emerald screenshots were supplied by the
user for the guide. `GuideImage` references them directly so the same component
can display them in both the wizard and About.

- `trainer-name.png` and `birch-final.png`: the first and second TID/SID timer cues.
- `starter-bag.png` and `starter-confirm.png`: the protected save position and
  the starter confirmation, shown together before starter identification.
- `box-placement.png` and `trainer-school.png`: Box 8, slot 5 and the curtains
  to inspect, shown together at the curtain step and in the About writeup.
- `starter-confirm.png` also accompanies the final shiny-attempt timer.

Pairs sit side by side on larger screens and stack on phones. The route
checklist and shiny-target selection stay image-free. No unused image
placeholders remain. The actual curtain viewer continues to use the
investigator's source-derived game artwork and byte mapping.
