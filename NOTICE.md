# Third-party material and attribution

The MIT license covers original application code and documentation. It does not grant rights to Pokémon graphics, names, game assets, contributed game records, or third-party code.

- **Pokémon Emerald assets:** the school background and binary graphics fixtures are extracted from pret/pokeemerald at commit `731ad5bfd6e6f265508d0efcca0ba42f9dcf5881`. They remain the property of their respective rights holders, including Nintendo, Game Freak and Creatures. No full ROM or save state is distributed.
- **pret/pokeemerald:** https://github.com/pret/pokeemerald. Source links and hashes are recorded in `research/RESEARCH.md` and `src/data/mapping.json`.
- **Investigator catalogs:** item names/IDs, holdability metadata and species growth rates are extracted from that same pinned pret source. The ACE Builder encounter taxonomy and PokéFinder generation research were inspected as references; no unrelated Builder application logic or PokéFinder implementation code is bundled.
- **Fresh-catch and experiment data:** base friendship and move PP come from the same pinned pret species/move data. Growth-table arithmetic, vitamin caps and move/PP/PP Up swapping were verified against its `experience_tables.h`, `pokemon.c` and `pokemon_summary_screen.c`. New-game SID seeding and generation were verified against `main.c`, `naming_screen.c`, `new_game.c` and `random.c`; see `research/SID_RNG.md`.
- **Wild RNG:** ordinary encounter tables are extracted from the same pinned pret source. Numeric golden outputs from [PokéFinder's Gen 3 tests](https://github.com/Admiral-Fish/PokeFinder/blob/master/Test/Gen3/wild3.json) independently check the original H1/H2/H4 implementation. These test facts are attributed in the tests and research documentation.
- **mGBA:** https://mgba.io/. Minimal cropped capture evidence and memory extracts are retained for independent regression checks. The emulator is not bundled.
- **Dewford/Feebas SID research:** maractite’s [original method](https://www.reddit.com/r/pokemonrng/comments/16ei2ej/) and [retail example](https://www.reddit.com/r/u_maractite/comments/16dyods) underpin the phrase-membership workflow. Related tools are [Pokémon RNG’s Find SID with Feebas](https://www.pokemonrng.com/emerald-sid-feebas/), which credits Lincoln, HappyLappy and Shao for the [Python SID Finder](https://github.com/HappyLappy1/Lappy-Python-Scripts/tree/main/RSE_Trendy_Saying_2_SID), and mucksw’s [Feebas Tile Calculator](https://mucksw.github.io/Feebas-Tile-Calculator/). Additional inspected research references include [Goppier/FindingFeebas](https://github.com/Goppier/FindingFeebas) and [yuhasem/FeebasFinder](https://github.com/yuhasem/FeebasFinder). The application implements its source model independently; no third-party tool implementation is bundled. These credits concern RNG research, not the independently verified curtain mapping.
- **Background research:** [Bulbapedia's Trainer's School window tile quirks](<https://bulbapedia.bulbagarden.net/wiki/List_of_overworld_glitches_(Generation_III)#Trainer's_School_window_tile_quirks>) and [Glitch City researchers' black curtains documentation](https://nintyconservation.github.io/glitchcity.wiki/glitchcity.wiki/Black_curtains_glitch.html) informed the initial glitch description and historical storage/address reports. The application's exact mapping was independently checked against pret source and emulator captures.
- **Dependencies:** React, React DOM, Vite, TypeScript, tsx, Prettier and their dependencies retain their respective licenses in their npm packages. Dependency source trees are not bundled in the source ZIP.

This project is not affiliated with or endorsed by the Pokémon rights holders.
